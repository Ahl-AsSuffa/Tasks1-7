# CSharp Practice Tasks

Небольшой консольный проект на **C#**, содержащий 7 учебных заданий по основам языка и условным конструкциям.

## О проекте

Программа запускается в консоли и предлагает выбрать одно из семи заданий. После выбора соответствующий метод выполняет задачу и выводит результат.

Исходный код находится в файле `Program.cs`.

## Возможности

Программа содержит следующие задания:

1. **Сравнение двух чисел** — определяет, равны ли числа и какое из них больше.
2. **Проверка диапазона** — проверяет, находится ли число между 5 и 10.
3. **Проверка значения** — определяет, равно ли введённое число 5 или 10.
4. **Расчёт банковского вклада** — рассчитывает сумму с процентами в зависимости от размера вклада:
   - меньше 100 — 5%;
   - от 100 до 200 включительно — 7%;
   - больше 200 — 10%.
5. **Банковский вклад с бонусом** — выполняет расчёт из задания 4 и дополнительно добавляет бонус `+15`.
6. **Выбор операции** — позволяет выбрать сложение, вычитание или умножение.
7. **Калькулятор двух чисел** — принимает два числа и выполняет выбранную операцию: сложение, вычитание или умножение.

## Запуск

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <НАЗВАНИЕ_РЕПОЗИТОРИЯ>
```

### 2. Запуск

Если проект создан как .NET-проект:

```bash
dotnet run
```

Если используется Visual Studio, откройте проект и запустите его через **Run / Start**.

## Использование

После запуска программа выводит меню:

```text
Введите номер задачи 1/7:
```

Введите номер задания от `1` до `7`.

Если введено некорректное значение, программа сообщает об ошибке и предлагает повторить ввод.
